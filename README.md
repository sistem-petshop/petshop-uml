# Sistem Petshop

Dokumentasi perancangan **Sistem Informasi Petshop** menggunakan diagram UML.

## Deskripsi Proyek
Sistem Petshop adalah aplikasi yang membantu pengelolaan toko hewan peliharaan,
mulai dari pengelolaan data produk (makanan, aksesoris, obat), transaksi
penjualan, hingga layanan seperti grooming dan penitipan hewan. Sistem ini
dirancang agar pencatatan stok dan transaksi lebih rapi, cepat, dan minim
kesalahan dibanding pencatatan manual.

## Tujuan
- Mempermudah admin dalam mengelola produk dan stok
- Mempermudah kasir dalam memproses transaksi
- Mempermudah pelanggan dalam melihat produk dan memesan layanan

## Aktor
- **Admin**: mengelola data produk, layanan, dan laporan
- **Kasir**: memproses transaksi pembayaran
- **Pelanggan**: melihat produk, membeli, dan memesan layanan

## Fitur Utama
- Login
- Kelola data produk
- Kelola data pelanggan
- Transaksi penjualan
- Pemesanan layanan grooming
- Laporan penjualan
